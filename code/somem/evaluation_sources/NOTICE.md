# Scoring provenance

The BEAM rubric-nugget scoring protocol derives from Mem0. The public
`eval_beam_judge.py` snapshot uses neutral metadata fields and labels; its
SYSTEM_PROMPT, JUDGE_PROMPT, clamp_score and parse_judgment are unchanged from
the original local experiment source, SHA-256
8215b640998d9554ccddd814ce48fdba355db575e35de5eb82f9cdbe7b195b81.
The original experiment file and historical results are not modified.
